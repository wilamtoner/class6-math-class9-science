## १. सैद्धान्तिक अवधारणा तथा मुख्य सूत्रहरू

### १.१ परिमिति (Perimeter):
- आयतको परिमिति: $P = 2(l + b)$
- वर्गको परिमिति: $P = 4l$
- त्रिभुजको परिमिति: $P = a + b + c$

### १.२ क्षेत्रफल (Area):
- आयतको क्षेत्रफल: $A = l \times b \quad \left(l = \frac{A}{b}, \; b = \frac{A}{l}\right)$
- वर्गको क्षेत्रफल: $A = l^2 \quad (l = \sqrt{A})$
- छाया परेको भागको क्षेत्रफल: $A_{\text{छाया}} = A_{\text{बाहिरी}} - A_{\text{भित्री}}$

### १.३ आयतन (Volume):
- षट्मुखको आयतन: $V = l \times b \times h$
- घनको आयतन: $V = l^3 \quad (l = \sqrt[3]{V})$
- क्षमता: $1\text{ m}^3 = 1,000\text{ लिटर}$, $1,000\text{ cm}^3 = 1\text{ लिटर}$

### १.४ वृत्तको परिचय:
- व्यास $d = 2r$, अर्धव्यास $r = \frac{d}{2}$
- परिधि $C = 2\pi r = \pi d$ ($\pi \approx \frac{22}{7}$)

## २. अभ्यास १०.१ का सम्पूर्ण समाधानहरू (Exercise 10.1 — परिमिति)

### प्रश्न १: साँचो वा झुटो छुट्याउनुहोस्:
- **(क)** लम्बाइ र चौडाइलाई जोडेर आयतको परिमिति निकालिन्छ।
  - **उत्तर:** **झुटो (False)** *(कारण: $P = 2(l + b)$ हुन्छ, २ ले गुणन गर्नुपर्छ)*
- **(ख)** $15\text{ cm}$ लम्बाइ र $10\text{ cm}$ चौडाइ भएको पुस्तकको परिमिति $50\text{ cm}$ हुन्छ।
  - **उत्तर:** **साँचो (True)** *(कारण: $2(15 + 10) = 2 \times 25 = 50\text{ cm}$)*
- **(ग)** $6\text{ m}$ लम्बाइ र $2\text{ m}$ चौडाइ भएको टेबलको परिमिति $12\text{ m}$ हुन्छ।
  - **उत्तर:** **झुटो (False)** *(कारण: $2(6 + 2) = 16\text{ m}$ हुन्छ)*
- **(घ)** $2\text{ m}$ लम्बाइ र $1\text{ m}$ चौडाइ भएको आयतको परिमिति $6\text{ m}$ हुन्छ।
  - **उत्तर:** **साँचो (True)** *(कारण: $2(2 + 1) = 6\text{ m}$)*
- **(ङ)** वर्गको लम्बाइलाई ४ ले गुणन गरेर वर्गको परिमिति निकालिन्छ।
  - **उत्तर:** **साँचो (True)** *(कारण: $P = 4l$)*
- **(च)** $5\text{ m}$ लम्बाइ भएको वर्गाकार रुमालको परिमिति $25\text{ m}$ हुन्छ।
  - **उत्तर:** **झुटो (False)** *(कारण: $4 \times 5 = 20\text{ m}$ हुन्छ)*
- **(छ)** $4\text{ m}$ परिमिति भएको वर्गको लम्बाइ $1\text{ m}$ हुन्छ।
  - **उत्तर:** **साँचो (True)** *(कारण: $4 \div 4 = 1\text{ m}$)*

---

### प्रश्न २: आयत तथा वर्गको परिमिति:
- **(क)** $AB = 8\text{ cm}, BC = 5\text{ cm} \Rightarrow P = 2(8 + 5) = \mathbf{26\text{ cm}}$
- **(ख)** $AB = 15\text{ m}, BC = 5\text{ m} \Rightarrow P = 2(15 + 5) = \mathbf{40\text{ m}}$
- **(ग)** $PQ = 9\text{ cm}, QR = 6\text{ cm} \Rightarrow P = 2(9 + 6) = \mathbf{30\text{ cm}}$
- **(घ)** $XY = 12.5\text{ ft}, YZ = 7\text{ ft} \Rightarrow P = 2(12.5 + 7) = \mathbf{39\text{ ft}}$
- **(ङ)** $AB = 28\text{ cm}, BC = 15\text{ cm} \Rightarrow P = 2(28 + 15) = \mathbf{86\text{ cm}}$
- **(च)** $AB = 35\text{ ft}, BC = 35\text{ ft} \Rightarrow P = 4 \times 35 = \mathbf{140\text{ ft}}$
- **(छ)** $QR = RS = 40\text{ m} \Rightarrow P = 4 \times 40 = \mathbf{160\text{ m}}$

---

### प्रश्न ३: चित्रका नापका आकृतिहरूको परिमिति:
- **(क)** $l = 3\text{ cm}, b = 2\text{ cm} \Rightarrow P = 2(3 + 2) = \mathbf{10\text{ cm}}$
- **(ख)** $l = 5\text{ cm}, b = 3\text{ cm} \Rightarrow P = 2(5 + 3) = \mathbf{16\text{ cm}}$
- **(ग)** $l = 4.5\text{ cm} \Rightarrow P = 4 \times 4.5 = \mathbf{18\text{ cm}}$
- **(घ)** $l = 18.5\text{ ft}, b = 13.5\text{ ft} \Rightarrow P = 2(18.5 + 13.5) = \mathbf{64\text{ ft}}$

---

### प्रश्न ४ देखि ११ सम्मका व्यावहारिक समस्याहरू:
- **प्रश्न ४:** तौलिया ($l = 190\text{ cm}, b = 110\text{ cm}$):
  $$P = 2(190 + 110) = 2 \times 300 = \mathbf{600\text{ cm}} \text{ (वा } 6\text{ m)}$$
- **प्रश्न ५:** खेत ($l = 27\text{ ft}, b = 22\text{ ft}$):
  $$P = 2(27 + 22) = 2 \times 49 = \mathbf{98\text{ ft}}$$
- **प्रश्न ६:** रुमाल ($l = 25\text{ cm}$):
  $$P = 4 \times 25 = \mathbf{100\text{ cm}} \text{ (वा } 1\text{ m)}$$
- **प्रश्न ७:** चौर ($P = 360\text{ m}, b = 60\text{ m}$):
  $$l = \frac{P}{2} - b = \frac{360}{2} - 60 = 180 - 60 = \mathbf{120\text{ m}}$$
- **प्रश्न ८:** पलङ ($P = 22\text{ ft}, l = 6\text{ ft}$):
  $$b = \frac{P}{2} - l = \frac{22}{2} - 6 = 11 - 6 = \mathbf{5\text{ ft}}$$
- **प्रश्न ९:** जग्गा ($l = 2x, b = x, P = 42\text{ m}$):
  $$2(2x + x) = 42 \Rightarrow 6x = 42 \Rightarrow x = 7\text{ m}$$
  $$\text{चौडाइ } (b) = \mathbf{7\text{ m}}, \quad \text{लम्बाइ } (l) = \mathbf{14\text{ m}}$$
- **प्रश्न १०:** वर्ग ($P = 84\text{ cm}$):
  $$l = \frac{84}{4} = \mathbf{21\text{ cm}}$$
- **प्रश्न ११:** वर्गाकार चौर वरिपरि ३४० रुखहरू:
  $$\text{लम्बाइतर्फ रुख सङ्ख्या} = \frac{340}{4} = \mathbf{85\text{ ओटा रुखहरू}}$$

## ३. अभ्यास १०.२ का सम्पूर्ण समाधानहरू (Exercise 10.2 — क्षेत्रफल)

### प्रश्न १: खाली ठाउँ भर्नुहोस्:
- (क) **क्षेत्रफल**
- (ख) **$\text{cm}^2$**
- (ग) **$6\text{ m}^2$**
- (घ) **$15\text{ cm}^2$**
- (ङ) **$4$**
- (च) **ग्राफपेपर (एकाइ वर्ग गणना)**

---

### प्रश्न ३: आयत तथा वर्गको क्षेत्रफल:
- **(क)** $l = 5\text{ cm}, b = 3\text{ cm} \Rightarrow A = 5 \times 3 = \mathbf{15\text{ cm}^2}$
- **(ख)** $l = 18\text{ cm}, b = 7\text{ cm} \Rightarrow A = 18 \times 7 = \mathbf{126\text{ cm}^2}$
- **(ग)** वर्ग $l = 19\text{ cm} \Rightarrow A = 19^2 = \mathbf{361\text{ cm}^2}$
- **(घ)** $l = 14.2\text{ m}, b = 11.5\text{ m} \Rightarrow A = 14.2 \times 11.5 = \mathbf{163.3\text{ m}^2}$

---

### प्रश्न ४: लम्बाइ वा चौडाइ पत्ता लगाउने:
- **(क)** $l = 7\text{ ft}, A = 21\text{ ft}^2 \Rightarrow b = \frac{21}{7} = \mathbf{3\text{ ft}}$
- **(ख)** $l = 18\text{ cm}, A = 90\text{ cm}^2 \Rightarrow b = \frac{90}{18} = \mathbf{5\text{ cm}}$
- **(ग)** $b = 3.2\text{ m}, A = 38.4\text{ m}^2 \Rightarrow l = \frac{38.4}{3.2} = \mathbf{12\text{ m}}$
- **(घ)** $b = 1\text{ ft}, A = 15\text{ ft}^2 \Rightarrow l = \frac{15}{1} = \mathbf{15\text{ ft}}$

---

### प्रश्न ५: वर्गको लम्बाइ:
- **(क)** $A = 1\text{ cm}^2 \Rightarrow l = \sqrt{1} = \mathbf{1\text{ cm}}$
- **(ख)** $A = 121\text{ ft}^2 \Rightarrow l = \sqrt{121} = \mathbf{11\text{ ft}}$
- **(ग)** $A = 196\text{ m}^2 \Rightarrow l = \sqrt{196} = \mathbf{14\text{ m}}$
- **(घ)** $A = 625\text{ m}^2 \Rightarrow l = \sqrt{625} = \mathbf{25\text{ m}}$

---

### प्रश्न ६: छाया परेको भागको क्षेत्रफल:
- **(क)** बाहिरी $5 \times 4 = 20\text{ cm}^2$, भित्री $2 \times 1 = 2\text{ cm}^2 \Rightarrow 20 - 2 = \mathbf{18\text{ cm}^2}$
- **(ख)** बाहिरी $10 \times 8 = 80\text{ cm}^2$, भित्री $5 \times 3 = 15\text{ cm}^2 \Rightarrow 80 - 15 = \mathbf{65\text{ cm}^2}$
- **(ग)** बाहिरी $6 \times 5 = 30\text{ cm}^2$, भित्री खाली भाग $= 7\text{ cm}^2 \Rightarrow 30 - 7 = \mathbf{23\text{ cm}^2}$
- **(घ)** बाहिरी $12.5 \times 6 = 75\text{ cm}^2$, भित्री खाली भाग $= 30\text{ cm}^2 \Rightarrow 75 - 30 = \mathbf{45\text{ cm}^2}$

## ५. पाठ १० मिश्रित अभ्यासको सम्पूर्ण समाधान (Mixed Review — पृष्ठ १२६–१२७)

- **प्रश्न १:** ग्राफ कोठा गणना: (क) $24\text{ cm}^2$, (ख) $18\text{ cm}^2$, (ग) $9\text{ cm}^2$
- **प्रश्न २:** तौलिया ($l = 120\text{ cm}, b = 80\text{ cm}$):
  $$P = 2(120 + 80) = \mathbf{400\text{ cm}}, \quad A = 120 \times 80 = \mathbf{9,600\text{ cm}^2}$$
- **प्रश्न ३:** खेत ($A = 85\text{ ft}^2, b = 5\text{ ft}$):
  $$l = \frac{85}{5} = 17\text{ ft}, \quad P = 2(17 + 5) = \mathbf{44\text{ ft}}$$
- **प्रश्न ४:** वर्ग ($l = 45\text{ cm}$):
  $$P = 4 \times 45 = \mathbf{180\text{ cm}}, \quad A = 45^2 = \mathbf{2,025\text{ cm}^2}$$
- **प्रश्न ५:** चौर ($P = 280\text{ m}, b = 50\text{ m}$):
  $$l = \frac{280}{2} - 50 = \mathbf{90\text{ m}}, \quad A = 90 \times 50 = \mathbf{4,500\text{ m}^2}$$
- **प्रश्न ६:** वर्ग ($A = 196\text{ cm}^2$):
  $$l = \sqrt{196} = \mathbf{14\text{ cm}}, \quad P = 4 \times 14 = \mathbf{56\text{ cm}}$$
- **प्रश्न ७:** जग्गा ($l = 2x, b = x, A = 648\text{ m}^2$):
  $$2x^2 = 648 \Rightarrow x^2 = 324 \Rightarrow x = 18\text{ m}$$
  $$\text{लम्बाइ} = \mathbf{36\text{ m}}, \quad \text{चौडाइ} = \mathbf{18\text{ m}}, \quad \text{परिमिति} = 2(36 + 18) = \mathbf{108\text{ m}}$$
- **प्रश्न ८:** घनाकार वस्तु ($V = 1331\text{ cm}^3$):
  $$l = \sqrt[3]{1331} = \mathbf{11\text{ cm}}$$
- **प्रश्न ९:** षट्मुख ($V = 250\text{ m}^3, h = 5\text{ m}, l = 2x, b = x$):
  $$10x^2 = 250 \Rightarrow x^2 = 25 \Rightarrow x = 5\text{ m}$$
  $$\text{चौडाइ} = \mathbf{5\text{ m}}, \quad \text{लम्बाइ} = \mathbf{10\text{ m}}$$
- **प्रश्न १०:** वर्ग र आयत ($A = 16\text{ m}^2$):
  $$l_{\text{वर्ग}} = \sqrt{16} = 4\text{ m} \Rightarrow l_{\text{आयत}} = 2 \times 4 = 8\text{ m}$$
  $$b_{\text{आयत}} = \frac{16}{8} = \mathbf{2\text{ m}}$$
- **प्रश्न ११:** वृत्तका भागहरू: केन्द्रबिन्दु, अर्धव्यास ($r$), व्यास ($d = 2r$), परिधि ($C$), जीवा, चाप।
