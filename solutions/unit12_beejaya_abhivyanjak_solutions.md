## १. बीजीय अभिव्यञ्जनका आधारभूत नियमहरू
- **सजातीय पदको जोड र घटाउ:** केवल सजातीय पदहरू (समान चर र समान घाताङ्क) मात्र आपसमा जोड्न वा घटाउन सकिन्छ।
  $$m x^a + n x^a = (m + n)x^a, \quad m x^a - n x^a = (m - n)x^a$$
- **एकपदीय गुणन:** गुणाङ्कहरू गुणन गर्ने र समान चरका घाताङ्क जोड्ने ($x^a \times x^b = x^{a+b}$)।
- **विस्तारीकरण नियम:** $a(b + c) = ab + ac, \quad a(b - c) = ab - ac$
- **एकपदीय तथा द्विपदीय भाग:** $\frac{x^a}{x^b} = x^{a-b}, \quad \frac{A + B}{C} = \frac{A}{C} + \frac{B}{C}$

## २. अभ्यास १२.१ का सम्पूर्ण समाधानहरू (Exercise 12.1 Solutions)

### प्रश्न १: साँचो वा झूटो छुट्याउनुहोस्:
- **(क)** $x$ र $3$ लाई जोड्दा $3x$ हुन्छ। $\implies$ **झूटो (False)** [जोड्दा $x + 3$ हुन्छ]
- **(ख)** $x$ को मान ५ भए $x$ लाई अचल राशि भनिन्छ। $\implies$ **साँचो (True)** [मान निश्चित ५ तोकिएपछि स्थिर रहन्छ]
- **(ग)** $2a$ र $4a^2$ लाई जोड्दा $6a^2$ हुन्छ। $\implies$ **झूटो (False)** [विजातीय पद भएकाले जोड्न मिल्दैन]
- **(घ)** $5x$ बाट $2x$ घटाउँदा $3x$ हुन्छ। $\implies$ **साँचो (True)** [$5x - 2x = 3x$]
- **(ङ)** $x - 2 = 8$ मा $x$ को मान १० हुन्छ। $\implies$ **साँचो (True)** [$x = 8 + 2 = 10$]
- **(च)** यदि $y = 1$ भए $y^2 + 1$ को मान ३ हुन्छ। $\implies$ **झूटो (False)** [$1^2 + 1 = 2$]
- **(छ)** यदि $x = 2, y = 3$ भए $x^2 + y^2$ को मान ३ हुन्छ। $\implies$ **झूटो (False)** [$2^2 + 3^2 = 4 + 9 = 13$]

### प्रश्न २: चर वा अचल राशि छुट्याउनुहोस्:
- **(क)** $x$ ले तपाईंसँग भएका किताबहरूको संख्यालाई जनाउँछ। $\implies$ **चर राशि (Variable)**
- **(ख)** $y$ ले तपाईंको विद्यालयमा हुनुभएका जम्मा शिक्षकहरूको संख्यालाई जनाउँछ। $\implies$ **चर राशि (Variable)**
- **(ग)** $z$ ले २ र ४ बीचको बिजोर संख्यालाई जनाउँछ। $\implies$ **अचल राशि (Constant)** [मान निश्चित रूपमा ३]
- **(घ)** $a$ को मान ७ हुन्छ। $\implies$ **अचल राशि (Constant)**
- **(ङ)** $b$ ले १ र ९ बीचका गन्ती संख्याहरूलाई जनाउँछ। $\implies$ **चर राशि (Variable)** [$b \in \{2, 3, \dots, 8\}$]
- **(च)** $c$ ले १ र २ को योगफललाई जनाउँछ। $\implies$ **अचल राशि (Constant)** [$1 + 2 = 3$ निश्चित]

### प्रश्न ५: घटाउनुहोस् (फरक निकाल्नुहोस्):
- **(क)** $(3x + 4y) - (2x + 2y) = 3x - 2x + 4y - 2y = \mathbf{x + 2y}$
- **(ख)** $(6a + 4b) - (a + b) = 6a - a + 4b - b = \mathbf{5a + 3b}$
- **(ग)** $(6x + 7y + 8z) - (2x + 3y + 4z) = \mathbf{4x + 4y + 4z}$
- **(घ)** $(4a - 3b + 5c) - (2a + b - 3c) = 4a - 2a - 3b - b + 5c + 3c = \mathbf{2a - 4b + 8c}$
- **(ङ)** $(7a - 5b - 7c) - (a - 2b - 3c) = 7a - a - 5b + 2b - 7c + 3c = \mathbf{6a - 3b - 4c}$
- **(च)** $(2x^2 - xy + y^2) - (x^2 - xy + 2y^2) = 2x^2 - x^2 - xy + xy + y^2 - 2y^2 = \mathbf{x^2 - y^2}$
- **(छ)** $(6x^3 + 5x^2y + y^3) - (2x^3 + 3x^2y + 4y^3) = \mathbf{4x^3 + 2x^2y - 3y^3}$

### प्रश्न ६: सरल गर्नुहोस्:

## ४. अभ्यास १२.३ का सम्पूर्ण समाधानहरू (Exercise 12.3 Solutions)

- **(क)** $ab \div a = \mathbf{b}$

### प्रश्न २: द्विपदीयलाई एकपदीयले भाग:
- **(क)** $(xy + xz) \div x = \frac{xy}{x} + \frac{xz}{x} = \mathbf{y + z}$
- **(ख)** $(x^2 - 2xy) \div x = \frac{x^2}{x} - \frac{2xy}{x} = \mathbf{x - 2y}$
- **(ग)** $(a^2bc + abc^2) \div abc = \frac{a^2bc}{abc} + \frac{abc^2}{abc} = \mathbf{a + c}$
- **(घ)** $(5l^2m - 15lm^2) \div 5lm = \frac{5l^2m}{5lm} - \frac{15lm^2}{5lm} = \mathbf{l - 3m}$
- **(ङ)** $(14p^3q^2 + 49p^2q^3) \div 7p^2q^2 = \mathbf{2p + 7q}$
- **(च)** $(36ax^3y^3 - 18bx^2y^2) \div 9x^2y^2 = \mathbf{4axy - 2b}$
- **(छ)** $(40u^3v^2 - 24u^2v^3) \div 8u^2v^2 = \mathbf{5u - 3v}$

### प्रश्न ३: सम्भावित लम्बाइ र चौडाइ:

### प्रश्न ५: आयत $ABCD$ ($l = 2x + y, b = 2x$):
- **(क) परिमिति:** $P = 2[(2x + y) + 2x] = 2(4x + y) = \mathbf{8x + 2y}$
- **(ख) क्षेत्रफल:** $A = 2x(2x + y) = \mathbf{4x^2 + 2xy}$
- **(ग) $\Delta ABD$ को क्षेत्रफल:** $\frac{1}{2} A = \mathbf{2x^2 + xy}$
- **(घ) लम्बाइमा घटाउनुपर्ने परिमाण:** चौडाइ $2x$ सँग बराबर बनाउन **$\mathbf{y}$ घटाउनुपर्छ**।
- **(ङ) बनेको वर्गको क्षेत्रफल:** भुजा $2x$ भएको वर्गको क्षेत्रफल $= (2x)^2 = \mathbf{4x^2}$
