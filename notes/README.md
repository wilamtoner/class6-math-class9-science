# कक्षा ६ गणित - पूर्ण अध्ययन नोटहरू (Class 6 Mathematics Notes)

नेपाल सरकार, शिक्षा, विज्ञान तथा प्रविधि मन्त्रालय, **पाठ्यक्रम विकास केन्द्र (CDC)** द्वारा निर्धारित कक्षा ६ को नयाँ पाठ्यक्रममा आधारित सम्पूर्ण २० वटै पाठहरूको विस्तृत अध्ययन नोट।

प्रत्येक पाठमा:
1. **सैद्धान्तिक अवधारणा तथा परिचय (Core Concepts)**
2. **महत्त्वपूर्ण सूत्र, नियम र LaTeX समीकरणहरू (Key Formulas & LaTeX Equations)**
3. **३ तहका प्रश्न समाधान विधि (3 Tiers of Question Solving):**
   - **आधारभूत बुझाइ (Basic Understanding / Knowledge Level)**
   - **ज्ञानको प्रयोग तथा सीप (Knowledge Base / Application Level)**
   - **उच्च दक्षता तथा समस्या समाधान (Higher Ability / Problem Solving Level)**
4. **विद्यार्थीहरूले गर्ने साझा गल्तीहरू र बच्ने उपायहरू (Common Mistakes & Pro Tips)**
