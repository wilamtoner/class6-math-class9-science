एकाइ ३: क्षेत्रमिति (Unit 3: Mensuration — पहिलो पाठ)

पाठ ९: दूरी (Distance)

पाठ्यपुस्तक पृष्ठ १०६–११० अभ्यास ९ तथा परियोजना कार्य
१

दूरी (Distance) र नापका प्रणालीहरू

कुनै दुई निश्चित बिन्दुहरू बीचको कुल लम्बाइ वा अन्तरलाई दूरी (Distance / Length) भनिन्छ। दूरीको अन्तर्राष्ट्रिय मानक एकाइ (SI Unit) मिटर ($m$) हो।

प्रमुख दुई प्रणालीहरू:
• मेट्रिक प्रणाली (Metric): मिलिमिटर ($mm$), सेन्टिमिटर ($cm$), मिटर ($m$), किलोमिटर ($km$)
• इम्पेरियल प्रणाली (Imperial): इन्च ($in$), फिट ($ft$), गज ($yd$), माइल ($mile$)
२

एकाइ रूपान्तरणको सुनौलो नियम

नियम १ (ठूलो $ o$ सानो): ठूलो एकाइबाट सानो एकाइमा जाँदा रूपान्तरण दरले गुणन ($ imes$) गरिन्छ।
उदा: $5\text{ m} = 5 \times 100 = 500\text{ cm}$; $6\text{ ft} = 6 \times 12 = 72\text{ in}$
नियम २ (सानो $ o$ ठूलो): सानो एकाइबाट ठूलो एकाइमा जाँदा रूपान्तरण दरले भाग ($\div$) गरिन्छ।
उदा: $480\text{ cm} = \frac{480}{100} = 4.8\text{ m}$; $36\text{ in} = \frac{36}{12} = 3\text{ ft}$

प्रश्न १: खाली ठाउँ भर्नुहोस् (Fill in the blanks)

५ प्रश्नहरू
(क) $1\text{ m}$ मा 100 $\text{cm}$ हुन्छ।

कारण: मेट्रिक प्रणाली अनुसार $1\text{ m} = 100\text{ cm}$।

(ख) $3\text{ ft}$ लामो शैक्षिक पाटीको लम्बाइ 36 $\text{in}$ हुन्छ।

कारण: $3 \times 12\text{ in} = 36\text{ in}$।

(ग) तपाईँ $500\text{ m}$ हिँडेर विद्यालय आइपुग्नुभयो भने तपाईँ 1640 $\text{ft}$ हिँड्नुभयो।

कारण: $500 \times 3.28\text{ ft} = 1640\text{ ft}$।

(घ) बेन्चको लम्बाइ $250\text{ cm}$ छ भने सो बेन्च 8.2 $\text{ft}$ लामो हुन्छ।

कारण: $\frac{250}{30.48} \approx 8.202\text{ ft} \approx 8.2\text{ ft}$।

(ङ) कक्षाकोठाको भुइँको लम्बाइ $500\text{ cm}$ रहेछ भने सो कोठाको लम्बाइ 196.85 (वा पुस्तकको मुद्रण अनुसार 188.98) $\text{in}$ हुन्छ।

कारण: $500 \div 2.54 = 196.85\text{ in}$। (पाठ्यपुस्तक उत्तरकुञ्जिकामा उदाहरण ३ को $480\text{ cm}$ को उत्तर $188.98$ छापिएको)।

प्रश्न २: तल दिइएका सबै नापलाई सेन्टिमिटर ($\text{cm}$) मा बदल्नुहोस्

४ उप-प्रश्नहरू
(क) $3\text{ m } 60\text{ cm}$

= $3 \times 100\text{ cm} + 60\text{ cm}$
= $300 + 60$ = 360 cm

(ख) $6\text{ ft}$

($1\text{ ft} = 30.48\text{ cm}$)
= $6 \times 30.48\text{ cm}$ = 182.88 cm

(ग) $8\text{ ft } 6\text{ in}$

इन्चमा: $(8 \times 12 + 6) = 102\text{ in}$
$\text{cm}$ मा: $102 \times 2.54\text{ cm}$ = 259.08 cm

(घ) $11\text{ ft } 10\text{ in}$

इन्चमा: $(11 \times 12 + 10) = 142\text{ in}$
$\text{cm}$ मा: $142 \times 2.54\text{ cm}$ = 360.68 cm

प्रश्न ३: तल दिइएका सबै नापलाई इन्च ($\text{in}$) मा बदल्नुहोस्

(क) $7\text{ m}$

= $7 \times 39.37\text{ in} = 275.59\text{ in} \approx$ 275.60 in

(ख) $15\text{ m } 30\text{ cm}$

= $15.3\text{ m} \times 39.37\text{ in} = 602.361 \approx$ 602.36 in

(ग) $7\text{ ft } 8\text{ in}$

= $(7 \times 12) + 8 = 84 + 8 =$ 92 in

(घ) $25\text{ ft } 6\text{ in}$

= $(25 \times 12) + 6 = 300 + 6 =$ 306 in

प्रश्न ४: तल दिइएका सबै नापलाई फिट ($\text{ft}$) मा बदल्नुहोस्

(क) $9\text{ m } 40\text{ cm}$

= $9.4\text{ m} \times 3.28\text{ ft} = 30.832 \approx$ 30.83 ft

(ख) $14\text{ m } 25\text{ cm}$

= $14.25\text{ m} \times 3.28\text{ ft} =$ 46.74 ft

(ग) $46\text{ m } 75\text{ cm}$

= $46.75\text{ m} \times 3.28\text{ ft} =$ 153.34 ft

(घ) $32\text{ ft } 8\text{ in}$

= $32 + \frac{8}{12} = 32 + 0.667 \approx$ 32.67 ft

प्रश्न ५: तल दिइएका सबै नापलाई मिटर ($\text{m}$) मा बदल्नुहोस्

(क) $24\text{ m } 80\text{ cm}$

= $24 + \frac{80}{100} = 24 + 0.8 =$ 24.8 m

(ख) $53\text{ ft}$

= $\frac{53}{3.28}\text{ m} \approx$ 16.16 m (पुस्तक कुञ्जिका: 16.19 m)

(ग) $44\text{ ft } 10\text{ in}$

फिटमा: $44.833\text{ ft} \Rightarrow \frac{44.833}{3.28} \approx$ 13.67 m

(घ) $88\text{ ft } 6\text{ in}$

फिटमा: $88.5\text{ ft} \Rightarrow \frac{88.5}{3.28} \approx$ 26.98 m (पुस्तक कुञ्जिका: 24.54 m मुद्रण)

प्रश्न ६: खेतको लम्बाइ र चौडाइको फरक

उत्तर: ४००.१६ ft

प्रश्न: एउटा खेतको लम्बाइ $650\text{ ft } 10\text{ in}$ र चौडाइ $250\text{ ft } 8\text{ in}$ रहेछ भने चौडाइभन्दा लम्बाइ कति $\text{ft}$ ले बढी रहेछ?
समाधान:
$\text{फरक} = (650\text{ ft } 10\text{ in}) - (250\text{ ft } 8\text{ in}) = 400\text{ ft } 2\text{ in}$
फिटमा रूपान्तरण: $400 + \frac{2}{12} = 400 + 0.166... \approx$ 400.16 ft (वा 400.17 ft)।

प्रश्न ७: चौरको लम्बाइ र चौडाइको फरक

उत्तर: ५८८.६४ ft

प्रश्न: एउटा चौरको लम्बाइ $225\text{ m } 40\text{ cm}$ र चौडाइ $150\text{ ft } 8\text{ in}$ छ भने चौडाइभन्दा लम्बाइ कति $\text{ft}$ ले बढी रहेछ?
समाधान:
१. लम्बाइ $= 225.4\text{ m} \times 3.28 = 739.312\text{ ft}$
२. चौडाइ $= 150 + \frac{8}{12} = 150.667\text{ ft}$
३. $\text{फरक} = 739.312 - 150.667 =$ 588.64 ft।

प्रश्न ८: जोडिएको पर्खालको कुल लम्बाइ

उत्तर: ६३६.३५ m

प्रश्न: एउटा पर्खाल $567\text{ m } 50\text{ cm}$ लामो छ। त्यसैसँग जोडेर अर्को $225\text{ ft } 10\text{ in}$ लामो पर्खाल बनाइएको छ भने पर्खालको जम्मा लम्बाइ कति $\text{m}$ हुन्छ?
समाधान:
१. पहिलो पर्खाल $= 567.5\text{ m}$
२. दोस्रो पर्खाल $= 225 + \frac{10}{12} = 225.833\text{ ft} \Rightarrow \frac{225.833}{3.28} = 68.85\text{ m}$
३. $\text{जम्मा लम्बाइ} = 567.5 + 68.85 =$ 636.35 m।

प्रश्न ९: बाटो बनाउन बाँकी दूरी

उत्तर: १४,१९०.९२ ft

प्रश्न: एउटा $4567\text{ m } 20\text{ cm}$ लामो बाटो बनाउनुपर्नेमा $789\text{ ft } 6\text{ in}$ बाटो बनिसकेपछि कति बाटो बनाउन बाँकी रहन्छ?
समाधान:
१. कुल बाटो $= 4567.2\text{ m} \times 3.28 = 14,980.416\text{ ft}$
२. बनिसकेको बाटो $= 789.5\text{ ft}$
३. $\text{बाँकी बाटो} = 14,980.416 - 789.5 =$ 14,190.92 ft।

Bloom's Taxonomy आधारित

तह १: ज्ञान तह (Knowledge Level — ६ प्रश्न)

१. दूरी भनेको के हो? यसको SI एकाइ के हो?
कुनै दुई बिन्दुहरू बीचको कुल लम्बाइलाई दूरी भनिन्छ। यसको SI एकाइ मिटर ($m$) हो।
२. $1\text{ m}$ मा कति $\text{cm}$ र $\text{mm}$ हुन्छ?
$1\text{ m} = 100\text{ cm} = 1000\text{ mm}$ हुन्छ।
३. $1\text{ ft}$ मा कति इन्च ($\text{in}$) हुन्छ?
$1\text{ ft} = 12\text{ in}$ हुन्छ।
४. $1\text{ in}$ मा कति सेन्टिमिटर हुन्छ?
$1\text{ in} = 2.54\text{ cm}$ हुन्छ।
५. $1\text{ m}$ मा कति फिट ($\text{ft}$) हुन्छ?
$1\text{ m} = 3.28\text{ ft}$ हुन्छ।
६. ठूलोबाट सानो एकाइमा लैजाँदा कुन क्रिया गरिन्छ?
गुणन ($ imes$) क्रिया गरिन्छ।

तह २: बोध तथा प्रयोग तह (Application Level — ६ प्रश्न)

७. $12.5\text{ m}$ लाई $\text{cm}$ मा बदल्नुहोस्।
$12.5 \times 100 = $ 1250 cm
८. $72\text{ in}$ लाई फिट ($\text{ft}$) मा बदल्नुहोस्।
$\frac{72}{12} = $ 6 ft
९. $150\text{ cm}$ लामो टेबलको लम्बाइ इन्चमा कति हुन्छ?
$\frac{150}{2.54} \approx $ 59.06 in
१०. $2.5\text{ km}$ लाई मिटरमा बदल्नुहोस्।
$2.5 \times 1000 = $ 2500 m
११. $15\text{ ft } 9\text{ in}$ लाई दशमलव फिटमा बदल्नुहोस्।
$15 + \frac{9}{12} = 15 + 0.75 = $ 15.75 ft
१२. $16.4\text{ ft}$ लाई मिटरमा बदल्नुहोस्।
$\frac{16.4}{3.28} = $ 5 m

तह ३: उच्च दक्षता बहु-चरणीय समस्या (Higher Ability — ४ प्रश्न)

१३. $400\text{ m}$ को ट्र्याकमा ४ पटक दौडँदा कति $\text{km}$ र कति $\text{ft}$ दूरी पार हुन्छ?
कुल मिटर $= 400 \times 4 = 1600\text{ m}$।
किलोमिटरमा: $\frac{1600}{1000} = $ 1.6 km। फिटमा: $1600 \times 3.28 = $ 5,248 ft।
१४. मैदानको लम्बाइ $95\text{ m } 50\text{ cm}$ र चौडाइ $180\text{ ft } 4\text{ in}$ को अन्तर फिटमा निकाल्नुहोस्।
लम्बाइ $= 95.5 \times 3.28 = 313.24\text{ ft}$। चौडाइ $= 180 + \frac{4}{12} = 180.333\text{ ft}$।
अन्तर $= 313.24 - 180.333 = $ 132.91 ft।
१५. $45\text{ km}$ यात्रामा पहिलो दिन $18\text{ km } 400\text{ m}$ र दोस्रो दिन $42,650\text{ ft}$ पार गरेपछि कति मिटर बाँकी रहन्छ?
जम्मा $= 45,000\text{ m}$। पहिलो दिन $= 18,400\text{ m}$। दोस्रो दिन $= \frac{42650}{3.28} \approx 13,003.05\text{ m}$।
बाँकी $= 45000 - (18400 + 13003.05) = $ 13,596.95 m।
१६. $1.2\text{ km}$ तारबाट $250\text{ m } 80\text{ cm}$ र $1500\text{ ft}$ काट्दा बाँकी तार कति मिटर होला?
सुरुको तार $= 1200\text{ m}$। टुक्रा १ $= 250.8\text{ m}$। टुक्रा २ $= \frac{1500}{3.28} \approx 457.32\text{ m}$।
बाँकी $= 1200 - (250.8 + 457.32) = $ 491.88 m।
